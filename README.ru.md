# KOMPAS-3D viewer

**English version: [README.md](README.md)**

Просмотрщик родных файлов **КОМПАС-3D** в браузере. Читает бинарные форматы напрямую (без установленного КОМПАС, без сервера и конвертации), показывает 3D-модели на three.js, чертежи и спецификации — на canvas, и экспортирует их в **STL**, **DXF** и на печать.

> Статус: личный некоммерческий проект. Форматы файлов получены обратной разработкой (см. [`FORMAT.md`](FORMAT.md)), поэтому часть возможностей покрыта не полностью. Проверено на файлах КОМПАС-3D от v14 до v24.
> **Лицензия: все права защищены — использование только с письменного разрешения правообладателя. См. [Лицензия](#лицензия).**

## Возможности

### Поддерживаемые файлы

| Расширение | Содержимое | Что читается |
|---|---|---|
| `.m3d` | 3D-деталь | триангулированные грани всех тел, габариты, объём, площадь поверхности, сведения о файле и приложении |
| `.a3d` | 3D-сборка | компоненты с положением (поворот + сдвиг), берутся из приложенных `.m3d`; недостающие детали перечисляются |
| `.cdw` | чертёж | всё, что перечислено ниже в разделе «Чертежи» |
| `.frw` | фрагмент | тот же разборщик, что и для `.cdw` |
| `.spw` | спецификация | многолистовые спецификации по ГОСТ Р 2.106 |

Поддерживаются оба поколения контейнера: современный на основе ZIP (поток `Contents` из подряд идущих zlib-блоков) и старый плоский `KF…` (для старых сборок — экспериментально).

### 3D-модели и сборки
- Просмотр на WebGL (three.js): вращение, масштаб, сдвиг мышью и касаниями, кнопка «Вписать», рёбра и каркас.
- Список тел с цветом, размерами, числом треугольников и объёмом; каждое тело можно скрыть.
- Сборки: применяются положения компонентов, имена файлов сопоставляются терпимо (переименованные детали, кириллические двойники латиницы); проверено на крупных сборках (десятки экземпляров, ~100 тыс. треугольников).
- Общие размеры X × Y × Z, объём и площадь поверхности.

### Чертежи (`.cdw`, `.frw`)
- Отрезки, окружности, дуги, эллипсы и их дуги со **стилями линий** (основная, тонкая, осевая, штриховая, штрихпунктирная, волнистая…) — с реальными толщинами и штрихами.
- **Тексты**: выравнивание, поворот, высота, управляющие коды и **спецзнаки** (⌀ ° ± × α β γ τ Ⓜ ↻ ▭ I II ※ …) в тексте, значениях размеров, ячейках штампа и таблицах.
- **Размеры** всех типов: линейный, диаметр, радиус, угловой, ординатный; стрелки, значения, допуски.
- **Штриховка**, виды с масштабом, таблицы, **макроэлементы** (условные обозначения схем, знаки шероховатости и др.).
- **Рамка и основная надпись** (форма 1) со значениями; форматы A4 – A1, книжная и альбомная ориентация; чертежи в старом контейнере тоже.
- Холст с панорамой и масштабом, автоподбор.

### Спецификации (`.spw`)
- Разделы по ГОСТ Р 2.106 (документация, сборочные единицы, детали, стандартные изделия, материалы…), заголовки групп, дроби, переносы в наименованиях, спецзнаки.
- **Многолистовые** спецификации: первый лист (форма 1) и последующие (форма 2а) со своими рамками, штампами, «Лист / Листов» и полосой «Перв. примен.».
- Значения штампа: наименование, обозначение, разработал / проверил / н. контр., организация, первичное применение.

### Экспорт и печать
- **STL** (бинарный, миллиметры, система координат КОМПАС): все тела одним файлом либо по файлу на тело в одном `.zip`; можно только отмеченные в списке тела. Сборки выгружаются с учётом положения компонентов.
- **DXF** (R12, cp1251) для чертежей и спецификаций: слои по стилям линий, толщины полилиний, типы линий, тексты (кириллица; знаки через `%%c %%d %%p` / `\U+XXXX`).
- **Печать**: векторные страницы SVG, чёрное на белом, по странице на лист (многолистовая спецификация печатается несколькими страницами).

### Интерфейс
- Английский по умолчанию, переключатель **EN / RU** (запоминается).
- Адаптивная вёрстка: на телефоне боковая панель — выезжающее меню по кнопке ☰.
- Светлая / тёмная тема по настройкам системы.
- Перетаскивание файлов, встроенные примеры.
- Работает из `file://` — веб-сервер не нужен.

## Использование

1. Откройте `viewer.html` в современном браузере.
2. Нажмите **Открыть …** или перетащите файлы на страницу.
   Для сборки выберите `.a3d` **вместе с** её деталями `.m3d` (несколько файлов сразу).
3. В боковой панели — габариты, тела, параметры вида и экспорт.

Готовый бандл лежит в `dist/viewer.bundle.js`, поэтому для запуска сборка не нужна.

## Сборка и проверка

```bash
npm install          # только esbuild
npm run build        # dist/viewer.bundle.js (+ dist/samples.js со встроенными имеющимися примерами)
node tools/test.mjs  # быстрая проверка геометрии встроенного образца
```

## Структура репозитория

| Путь | Назначение |
|---|---|
| `viewer.html`, `src/` | интерфейс, 3D/2D-отрисовка, экспорт, переводы |
| `m3d.js` | разбор контейнера и 3D-геометрии (детали, сборки, старый формат) |
| `drawing.js`, `sheet-template.js` | разбор чертежей, рамка и штамп |
| `spec.js`, `symbols.js` | разбор спецификаций, спецзнаки |
| `FORMAT.md` | **описание форматов КОМПАС-3D, полученное обратной разработкой** |
| `vendor/` | three.js (MIT) |
| `tools/` | скрипты сборки и проверки |

## Ограничения

Не поддерживаются или поддерживаются частично: сплайны и точки в чертежах, повороты видов, часть знаков рамок допусков (несколько кодов спецзнаков не расшифрованы, показываются как □), некоторые варианты старых сборок. Подробный статус по каждой области — в `FORMAT.md`.
